# Social Media App 🗣️

A full-stack social media platform built with React, Node.js, AWS DynamoDB, and Tailwind CSS. Users can create and view posts with clean UI and real-time persistence.

## 🚀 Features

- ✅ Create new posts with author name, content, and image
- 🧠 Full CRUD support using DynamoDB and AWS SDK v3
- 🎨 Responsive and modern design with Tailwind CSS
- 🧪 Unit testing with Jest and coverage reporting
- 📦 Deployed via Netlify (or your platform of choice)

## 🧑‍💻 Technologies Used

| Frontend | Backend | Styling | AWS |
|----------|---------|---------|-----|
| React    | Node.js | Tailwind CSS | DynamoDB |
| Axios    | Express | PostCSS | AWS SDK v3 |
